# Phishing URL Detector
Бұл жүйе машиналық оқыту алгоритмдерін қолдана отырып, веб-сілтемелер (URL) мен электрондық хаттардағы фишингтік шабуылдарды нақты уақыт режимінде анықтауға арналған. Жүйе интернет қолданушыларын алаяқтық сайттардан және дербес деректердің ұрлануынан қорғау мәселесін шешеді.

## Мақсаты
Машиналық оқыту модельдері негізінде күмәнді сілтемелерді автоматты түрде талдап, олардың қауіпсіздік деңгейін дәл анықтайтын интеллектуалды веб-жүйе әзірлеу.

## Пайдаланушылар
* Пайдаланушы (User)
* Жүйе әкімшісі (Admin)

## Талаптар
1. Пайдаланушы тексергісі келетін күмәнді URL-сілтемені веб-интерфейске енгізіп, сканерлеуге жібереді.
2. Жүйе енгізілген сілтеменің синтаксистік және домендік белгілерін (feature extraction) автоматты түрде бөліп алады.
3. Машиналық оқыту моделі сілтемені талдап, оны «Қауіпсіз» немесе «Фишингтік» деп жіктейді.
4. Пайдаланушы экраннан тексеру нәтижесін, қауіп деңгейін (пайызбен) және егжей-тегжейлі есепті көреді.
5. Тіркелген пайдаланушы өзінің бұрын тексерген сілтемелер тарихын жеке кабинетінде қарай алады.
6. Пайдаланушы жүйе қате анықтаған жағдайда жаңа фишингтік сілтеме туралы шағым (feedback) жібере алады.
7. Жүйе әкімшісі пайдаланушылар жіберген сілтемелерді тексеріп, деректер базасын жаңартады және ML моделін қайта оқытады.
